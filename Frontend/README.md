# Frontend EventHub Ionic

Application Ionic 9 / Angular 22, avec composants standalone et configuration Capacitor 8.

Depuis la racine du dépôt, `npm start` démarre l’API sur le port 3001 et cette interface sur http://localhost:8100.

Pour lancer uniquement l’interface depuis ce dossier (API déjà démarrée) :

```bat
npm start
```

Pour compiler : `npm run build` ou `npm run ionic -- build`. Le résultat se trouve dans `www`.

Consultez le [README principal](../README.md), le [guide pédagogique](../docs/ionic-et-angular.md) et la [préparation native](../docs/mobile.md).
